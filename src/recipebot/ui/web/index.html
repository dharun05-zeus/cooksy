How it works

1 · Understand

The LLM turns your message into a small structured request (e.g. add_exclude: ["dairy"]). High-precision guards fix anything it drops or invents.

2 · Remember

Restrictions stay on for the whole conversation; "the second one" refers to the last results.

3 · Compute

Python computes every fact from the dataset: search over all recipes, exact statistics, ingredient matching, substitution evidence.

4 · Check

LLM output is validated: substitutes must have evidence, new ingredients must exist in the dataset, invented IDs or numbers are removed.

What the dataset does not contain

Cooking times, servings, ratings, nutrition and photos are not in the Recipe Box data, so this app never shows them. Ask about them and it will say so rather than guess.

Allergy note

Allergen checks read recipe text with word lists and exclude uncertain items too, but they are not a medical safety guarantee.
